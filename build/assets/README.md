# build/assets/ — assets de build

Ícones, licenças e fontes usados no empacotamento.

| Arquivo | Contrato |
|---|---|
| `icons/` | Ícones do app e do instalador |
| `licenses/` | Textos de licença de binários redistribuídos |
| `src/` | Recursos de origem para gerar assets |

## Invariantes

- Licenças de terceiros devem acompanhar os binários.
